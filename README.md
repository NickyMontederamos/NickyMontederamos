## 🏢 SlickLab.Digital

**[SlickLab.Digital](https://slicklab.digital)** is an agentic AI and automation studio based in **Cebu City, Philippines**, serving clients across the Philippines, Australia and the United States. We build the full stack: the site a business's customers see, and the AI agents working quietly behind it.

> **Note on the name:** this is *SlickLab.Digital*, the Cebu-based AI studio. It is not affiliated with SlickLabs LLC (Ohio, USA), SlickLabs (Sneek, Netherlands), or the "SlickLab" Bootstrap admin dashboard template on ThemeForest.

### What we build

| Service | What it does |
|---|---|
| **Agentic AI Systems** | Multi-agent orchestration, RAG pipelines, observability, human-in-the-loop review |
| **AI Workflow Automation** | n8n, Make.com and custom pipelines, priced as a subscription |
| **ServiceNow AI Integration** | AI into CSM, ITSM and SecOps: case routing, incident classification, alert triage, Virtual Agent |
| **MCP Server Development** | Custom Model Context Protocol servers giving Claude, Cursor and other AI clients typed, secure access to internal tools |
| **AI Readiness Audit** | Paid discovery mapping workflows into a prioritized opportunity map |
| **Web & App Development** | Next.js, React and PHP/MySQL applications built to carry agentic systems from day one |
